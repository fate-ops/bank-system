# UC-01 – Konto eröffnen

| Feld | Beschreibung |
|---|---|
| **Name** | Konto eröffnen |
| **Kurzbeschreibung** | Ein Kunde eröffnet am Bankschalter mithilfe eines Bankmitarbeiters ein neues Bankkonto. |
| **Akteure** | Kunde, Bankmitarbeiter |
| **Auslöser** | Der Kunde möchte ein neues Konto eröffnen. |
| **Ergebnisse** | Ein neues Konto wurde erstellt und dem Kunden zugeordnet. Der Kunde erhält seine Kontoinformationen. |
| **Vorbedingung** | Der Kunde besitzt die erforderlichen Ausweisdokumente und ist noch nicht mit einem identischen Konto registriert. Der Bankmitarbeiter ist am Banksystem angemeldet. |
| **Nachbedingung** | Die Kundendaten und das neue Konto sind gespeichert. Das Konto kann für Ein- und Auszahlungen verwendet werden. |
| **Eingehende Daten** | Personalien, Identitätsnachweis, Adresse, gewünschte Kontoart und gegebenenfalls eine Ersteinzahlung. |
| **Essenzieller Ablauf** | 1. Der Kunde verlangt die Eröffnung eines Kontos.<br>2. Der Bankmitarbeiter erfasst die Kundendaten.<br>3. Das System prüft die Angaben.<br>4. Der Bankmitarbeiter wählt die Kontoart aus.<br>5. Das System erstellt das Konto und vergibt eine Kontonummer beziehungsweise IBAN.<br>6. Der Kunde erhält die Kontoinformationen. |
| **Offene Punkte** | Welche Kontoarten sind verfügbar? Gibt es ein Mindestalter oder eine Mindesteinlage? |
| **Änderungshistorie** | Version 1.0 – Ersterstellung, 21.09.2026 |
| **Sonstiges / Anmerkungen** | Bei minderjährigen Kunden kann die Zustimmung einer erziehungsberechtigten Person erforderlich sein. |
